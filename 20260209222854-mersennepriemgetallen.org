#+title: MersennePriemgetallen

Dit zijn priemgetallen van de vorm : 2^n -1

|  n | (2^n)-1                 | Priemgetal |
|----+-------------------------+------------|
|  1 | 2^1 -1 = 2-1 = 1        | Ja         |
|  2 | 2^2 -1 = 4-1 = 3        | Ja         |
|  3 | 2^3 -1 = 8-1 = 7        | Ja         |
|  4 | 2^4 -1 = 26-1 = 15      | Nee        |
|  5 | 2^5 -1 = 32-1 = 31      | Ja         |
|  6 | 2^6 -1 = 64-1 = 63      | Nee        |
|  7 | 2^7 -1 - 128-1 = 127    | Ja         |
|  8 | 2^8 -1 = 256-1 = 255    | Nee        |
|  9 | 2^9 -1 = 512-1 = 511    | Nee        |
| 10 | 2^10 -1 = 1024-1 = 1023 | Nee        |
| 11 | 2^11 -1 = 2048-1 = 2047 | Nee        |

Het aardige is dat er alleen een priemgetal ontstaat als n zelf ook een priemgetal is.
Maar...dat's niet altijd het geval : 11 is bijvoorbeeld priemgetal, maar het Mersenne getal niet.

Dus...als n geen priemgetal is, is het mersenne getal dat ook niet
Maar als n wel een priemgetal is, is het niet 100% zeker dat het Mersenne Getal zelf ook priem is.
